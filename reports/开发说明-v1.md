```
ui  ──►  services  ──►  providers  ──►  core
(PyQt5)   (无GUI)        (可网络)         (纯逻辑)
```

- `core/` 不 import PyQt5、不 import requests（已用 grep 校验，无匹配）。
- `providers/`、`services/` 不 import PyQt5。
- 仅 `ui/` 依赖 PyQt5；`import weather_app.ui` 不会加载 PyQt5（已校验），
  只有 `import weather_app.ui.main_window` 才会加载 Qt 控件类，且无需预先创建 QApplication。

## 3. 关键设计说明

### 3.1 core 层
- **models**：`WeatherRecord(date, condition, temp_c, humidity, wind_kph, source)`；
  天气状况常量：`SUNNY/CLOUDY/OVERCAST/RAIN/SNOW/FOG/DRIZZLE/THUNDER`（`ALL_CONDITIONS` 汇总）；
  来源常量：`SOURCE_OPEN_METEO`、`SOURCE_OFFLINE`。内部温度一律以摄氏度存储。
- **date_utils**：`parse_date` 先用正则 `^\d{4}-\d{2}-\d{2}$` 强制补零，再用 `strptime`
  校验日期真实存在（`2023-1-1`、`2023-02-30` 均抛 `ValueError`）。
  支持范围 = `[1940-01-01, 今天 + 16 天]`（`MAX_FORECAST_DAYS = 16`）。
- **units**：`c_to_f`/`f_to_c` 与 `format_temperature`（形如 `23.4 °C` / `74.1 °F`）。
- **formatting**：状况→中文名/emoji、来源→中文说明；`render_record` 输出展示字段字典。

### 3.2 providers 层
- **base**：`WeatherProvider(ABC)`，抽象方法 `fetch(day)`。
- **offline**：基于日期字符串的 **SHA-256 稳定哈希**生成温度/状况/湿度/风速，
  同一天永远同结果；按月份取季节基准温度与天气状况池，使样例数据更贴近真实；
  **完全离线、不 import requests**。
- **open_meteo**：默认上海（lat 31.23, lon 121.47），超时 8s；`requests.Session` 可注入。
  - `day >= today` → 预报接口 `api.open-meteo.com/v1/forecast`；
    `day < today` → 归档接口 `archive-api.open-meteo.com/v1/archive`。
  - 越界 → `DateOutOfRangeError`；网络/HTTP/解析失败 → `WeatherUnavailableError`。
  - WMO 天气码经 `map_wmo_code` 映射到内部状况常量；温度取当日最高/最低温均值。

### 3.3 services 层
- `WeatherService.get_weather(day, use_online=True)`：
  - 在线成功 → 返回在线记录并缓存；
  - `WeatherUnavailableError`（无网/失败）→ **自动降级**到 `OfflineProvider`，
    结果 `source` 标记为 `offline`，并置 `last_fallback = True`；
  - `DateOutOfRangeError`（日期本身不可查询）→ 直接上抛，由界面友好提示（不降级）；
  - 内存缓存键 `(来源类别, 日期)`，同一来源同一日期只取一次。

### 3.4 ui 层
- 日期控件默认今天、日历弹出、格式 `yyyy-MM-dd`，范围 1940-01-01 ~ 2100-12-31；
  「今天」按钮可一键回到今天。
- 「优先使用在线数据」开关默认开启；关闭时 `use_online=False` 强制走离线样例，
  便于**断网演示**。
- 温度单位切换（摄氏/华氏，默认摄氏）：切换时**直接用新单位重渲染**，不重复请求。
- 结果区展示：大号 emoji + 天气状况文字、日期、温度、湿度、风速、数据来源。
- 错误与提示：越界日期、数据不可用、以及「离线示例数据」提示均以**内联提示 + 状态栏**
  呈现，**不弹模态框、不崩溃**；查询逻辑外层有 `except Exception` 兜底。

## 4. 需求对照

| 需求 | 实现位置 |
|---|---|
| F1 日期选择（默认今天） | `ui/main_window.py`（`QDateEdit` + `_today_qdate`） |

| F5 非法/超范围/网络失败友好提示 | `core/date_utils.parse_date`、`core/errors`、`ui._show_message` |
| F6 摄氏/华氏切换（默认摄氏） | `core/units.py` + `ui/main_window.py::_on_unit_change` |
